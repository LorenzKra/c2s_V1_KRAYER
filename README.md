# Carbon to Silicon – Gebäudekonfigurator

## Konzept
Der Konfigurator ermöglicht die parametrische Gestaltung eines innerstädtischen Gebäudes auf Basis eines 3 × 3-Meter-Rasters. Gebäudegröße, Geschosszahl und Nutzung lassen sich individuell anpassen und direkt in 3D visualisieren. Zusätzlich können die Grundrisse der einzelnen Geschosse betrachtet und wichtige Flächen- und Nachhaltigkeitskennwerte ausgewertet werden.

## Testanleitung
1. Repository öffnen oder herunterladen.
2. `index.html` in Chrome oder Firefox starten.
3. Gebäudeparameter verändern und die 3D-Ansicht drehen.
4. Über die Geschossnavigation die einzelnen Grundrisse ansehen.
